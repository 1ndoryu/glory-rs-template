### Gotchas
- El parser legacy del gate no acepta `SNT-13` como ID de tarea; el gate real debe usar un ID del proyecto.
- El report namespace es branch-scoped; `observe-compare` conserva reportes canónicos, usa `--run-id` y verifica `generatedAt` fresco.

- La validación lexical se complementa con rechazo de symlink/junction ancestors; no se permite un output fuera del workspace o de `.quality-reports`.
- La paridad local de etapas no es todavía el schema upstream ni una prueba multi-proyecto.
