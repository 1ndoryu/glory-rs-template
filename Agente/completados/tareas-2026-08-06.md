### Gotchas
- El manifest no permite perfiles o stages desconocidos; un stage declarado sin factory falla cerrado.
- La allowlist base excluye credenciales y el validador rechaza nombres sensibles (`DATABASE_URL`, tokens, keys, passwords y similares); no se habilita una vía implícita para transportar secretos.
- `CARGO_TARGET_DIR_BASE` también queda fuera del manifest vigente: el target se resuelve por el adapter de Cargo/DB y no se expone a todos los stages.
- El legacy fallback de `stageDefinitions` existe únicamente para tests/compatibilidad durante la ventana de transición; un manifest faltante o inválido falla cerrado en el gate real.
- Paths dentro de `.quality-reports` rechazan symlink/junction existentes que escapen del workspace; hay fixture temporal de symlink en la suite.
- Observe end-to-end se salta si el CLI Sentinel no está provisionado o el checkout analizador está dirty; un skip no equivale a paridad.
- El gate consumidor fue ejecutado, pero no es PASS en este worktree: Rust requiere `DATABASE_URL`/`.env` y el worktree no contiene esos secretos locales; frontend no tiene `node_modules`. No se copian secretos ni se falsea el resultado.
